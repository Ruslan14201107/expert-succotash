# expert-succotash
Expense Tracker — Трекер расходов Информация об авторе Имя и фамилия: Руслан Сафин Дата создания: 10 мая 2026 года

Описание программы Expense Tracker — это GUI-приложение для учёта личных расходов. Позволяет добавлять, просматривать и фильтровать записи о расходах, подсчитывать сумму за выбранный период, сохранять и загружать данные в формате JSON, а также удалять отдельные записи или весь список.

Возможности ✅ Добавление расходов с указанием суммы, категории и даты. ✅ Фильтрация по категории и дате. ✅ Подсчёт суммы расходов за выбранный период. ✅ Сохранение данных в JSON-файл. ✅ Загрузка данных из JSON-файла. ✅ Удаление выбранной записи. ✅ Очистка всего списка расходов. ✅ Валидация вводимых данных (проверка суммы, формата даты, заполненности полей). Инструкция по запуску Требования Python 3.6 или выше. Установленная библиотека Tkinter (обычно идёт в комплекте с Python). Запуск Откройте терминал или командную строку. Перейдите в директорию проекта: bash Копировать cd expenseTracker Запустите приложение: bash Копировать python main.py Примеры использования Добавление расхода Заполните все поля формы: Сумма: 1500. Категория: Еда. Дата: 08.05.2026. Нажмите кнопку «Добавить расход». Запись появится в списке внизу окна. Фильтрация По категории: Выберите категорию из списка и нажмите «Применить фильтр». По дате: Введите дату (ДД.ММ.ГГГГ) и нажмите «Применить фильтр». Для сброса фильтров нажмите «Сбросить». Подсчёт суммы за период Укажите начальную и конечную дату. Нажмите «Посчитать сумму» — результат появится в отдельном поле. Сохранение и загрузка Нажмите «Сохранить в JSON» — данные сохранятся в файл expenses_data.json. Нажмите «Загрузить из JSON» — данные загрузятся из файла expenses_data.json. Удаление Выберите запись в списке и нажмите «Удалить выбранную». Для удаления всех записей нажмите «Очистить всё» и подтвердите действие. Тестовые данные (примеры для проверки) Попробуйте добавить следующие расходы для тестирования:
